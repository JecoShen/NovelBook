# 文体定位
以轻喜剧为默认底色、以清晰行动为推进力的第三人称贴身叙事。把设定、情绪和笑点都落到角色正在看见、触碰、判断和执行的具体事情上；题材转为严肃时保留视角、信息和行动合同，按比例降低吐槽与玩梗。

# 叙事视角
- 默认第三人称贴身限知，感知范围锁定当前视角人物；不提前替角色和读者解释未知答案。
- 内心评价可以直接融入叙述，但必须紧跟动作、观察或判断，不脱离现场空转。
- 信息通过主动获取、试错、询问、触摸、查看和后果逐步揭示，让读者与角色同步知道。

# 句式与节奏
- 默认“铺陈动作或环境 → 短句落点”：长句负责连续动作和具体感，短句负责转折、发现、吐槽或悬念。
- 紧张场景可以用逗号串联动作，但随后必须有停顿、选择或结果，不能只有速度。
- 反问、插入句、夸张判断和自嘲适量使用；不要让正文变成连续段子。
- 重要信息和情绪转折尽量用动作、物件或身体反应证明，不依赖抽象总结。

# 段落与对话
- 段落以完整自然段为主，承载连续动作、思路和信息；短段只承担明确节奏功能。
- 对话可以独立成段，但台词前后要有动作、环境或道具承接。
- 台词短、准、有目的；用称呼、内容、停顿和动作区分人物，少写“用某种语气说道”。
- 对话可采用“接话 → 打岔 → 拉回正题”，打岔必须推动关系或信息，不得停在抬杠。

# 情绪与修辞
- 情绪先外化为呼吸、手指、步伐、视线、衣物、工具和环境变化；点名情绪后立即给出行为证据。
- 喜剧来自目标、身份与现实条件的错位；每个笑点之后接行动、决定或新问题。
- 比喻、拟人和陌生化优先取当前场景可触摸的事物，少而准，避免连续使用同一类意象。
- 宏大设定和日常细节可以并置，但严肃损失、恐惧和关系变化不能一律被吐槽抹平。

# 格式化信息
- 系统、公告、契约、任务等可用简短格式分行呈现。
- 格式化信息之后必须紧跟角色的理解、误读、反应或行动；不连续讲资源、规则和历史背景。

# 正确示例（原创）
> 电梯停在十九层，门缝里先漏进一股烤红薯的甜味。
>
> 她低头看了看手里的委托单，又看了看头顶闪烁的红灯。
>
> “抓鬼的地址，为什么会有烤红薯？”
>
> 门开了。走廊尽头坐着一个抱纸袋的老人，脚边蹲着三只影子。
>
> 她把委托单折好，顺手摸出一枚硬币。先问清楚红薯多少钱，再问鬼是谁。

# 错误示例（原创）
> 她非常紧张、害怕、激动，内心充满了复杂的情绪。这个神秘组织拥有悠久历史和强大力量，她即将承担改变世界的重要使命。
>
> 不是这样，也不是那样，而是这样；她不是走过去，而是冲了过去。
>
> 叮！叮！叮！任务、奖励、技能、等级、命运同时出现，所有信息一股脑砸向读者。

# 核心禁区
- 不复刻参考正文的专名、角色、事件、完整桥段或连续原句。
- 不用大段旁白替代现场，不用抽象形容词替代动作和物件。
- 不把每段末尾都写成笑点，不把每个动作拆成口号式短行。
- 不连续堆拟声词、网络梗、夸张数字、固定身体部位或“沉默/语塞”类反应。
- 不使用“不是……而是……”及其变体作为主要转折；用动作、停顿、反问、但字或结果完成转折。
- 不为了降低 AI 痕迹删除剧情、压缩人物声音或牺牲合理篇幅。

# 生成自检
1. 视角是否贴身且没有越权信息？
2. 设定是否由角色获取并被角色消化？
3. 长短句和段落是否有节奏变化，短段是否有功能？
4. 对话是否有动作承接，是否避免语气标签？
5. 情绪是否有身体或行为证据，重要情绪是否被保留？
6. 笑点是否推动了后续行动或选择？
7. 修辞是否少而准，是否出现固定模板重复？
8. 是否出现来源专名、原句或可识别桥段？
