## §4 错误处理

### 4.1 P2-5 scan-scene-master-list.cjs 错误处理

| 场景 | 行为 |
|---|---|
| `manuscript/` 找不到 | 输出 `{ error: "no manuscript dir" }` 不退出 (退出码 0, 跟 P1-4 baseline-scan 一致) |
| 章节无 frontmatter | 跳过 + 计入 `skipped: N` 不报错 |
| frontmatter 缺 `chapter:` 字段 | 用目录名数字 fallback, 标 `auto-derived: true` |
| frontmatter 缺 `beat:` 字段 | 留空, 标 `beat: ""` (符合 i128 当前 V1+V2 100% 命中预期) |
| frontmatter 缺 `pov:` 字段 | 留空, 标 `pov: ""` |
| 章节无 `## 场景` 段 | `scene: 0` (符合 P1-4 baseline 0/80 预期) |
| Markdown table 输出超 200 行 | 切片 (每 50 章一表) |
| 报告写失败 | 沿用 i129 baseline 模式 (mkdir-p + try-catch) |

### 4.2 P2-5 表维护错误处理 (V3 写作期填 value_shift / hook_type)

| 场景 | 行为 |
|---|---|
| 列错位 (8 列被改 7/9 列) | llmlint 不报 (P2-5 不入 ruleset, 调研报告 §7.4 抗反模式) |
| `value_shift` 留空 | 允许 (P2-5 决策: V1+V2 留空) |
| `hook_type` 填错枚举 | 允许 (P2-5 决策: 不强制) |
| 同章多 scene | 暂不支持 (P2-5 决策: 1 章 1 行, 5 诫命子段不强制) |

**显式不处理** (避免报告 §7.4 过度 spec 化):
- ❌ 缺 `## 场景` 段 → 不报错
- ❌ `value_shift` 留空 → 不报错
- ❌ `hook_type` 留空 → 不报错
- ❌ 跨章 `## 场景 N` 编号连续性 → 不检测
- ❌ 5 诫命子段 → 不强制
- ❌ baseline 报告触发任何 enforcement → 报告只读
