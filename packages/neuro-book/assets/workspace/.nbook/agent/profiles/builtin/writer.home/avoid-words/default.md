# Writer 避讳词汇与句式

以下规则来自创作宪法第20条。ERROR 级必须严格遵守，出现即需修改；WARNING 级尽量避免，出现需审查是否必要。

## ERROR 级（绝对禁止）

### 网络小说高频套路词
- 禁止："邪魅一笑""冷冽的眼神""嘴角勾起一抹神秘的弧度"等系列面部描写模板
- 禁止："凤眸""幽深的眸子""星辰般的眼眸"等过度形容眼睛的用词
- 禁止："娇躯""玉手""香肩"等物化/刻板形容
- 禁止："打了个响指""气场全开""瞬间碾压"等打脸套路用语
- 禁止："X爷""小妞""本尊""老子"等人称套话
- 禁止："XX出品，必属精品""这一切都在我的掌控之中"等标语句式

### 误用的金融术语
- 禁止："庄家""主力""洗盘""拉高出货"等散户炒股用语（男主是量化交易员，不用这套术语体系）
- 禁止："股神""从100万做到1个亿""翻了多少倍"等暴富叙事
- 禁止：用"交易就是赌博""金融就是骗局"等一概而论的正确废话

### 情感描写模板
- 禁止："一股暖流涌上心头""心中一片冰冷"等直接定义情绪的写法
- 禁止："眼泪不争气地流了下来"（"不争气"已经用烂了）
- 禁止："心里像打翻了五味瓶"（陈词滥调）

### AI高频词/互联网黑话
- 禁止："颤抖"作为万能身体反应词（生气也颤抖、害怕也颤抖、感动也颤抖）
- 禁止："极致""赋能""底层逻辑""闭环""抓手""对齐"等互联网/商业黑话

### 通用禁用词汇与句式
- 禁止使用以下词汇：一丝、不容置疑、不易察觉、几不可察
- 禁止使用以下句式：他没有……，而是……；不是……，而是……；与其说……不如说是……
- 禁止使用："不是……而是……""不容置疑""一丝XXX"等句式反复出现
- 如果想表达转折、对比或修正，直接写实际发生的动作、事实或判断，请换一种表述方式

### 句式多样性
- 同类句式连续出现不超过3次。写完一段后检查是否有重复句式。

## WARNING 级（尽量避免）

- "X总"后缀的过度使用（陆铮称赵明远为"赵总"是合理的，但全书不能所有人都在叫"X总"）
- 网络用语的滥用（"凡尔赛""躺平""内卷"——偶尔出现以建立时代感是允许的，但不要每段出现）
- 过度使用比喻——特别是"像……一样""仿佛……"句式（每章节不超过2-3处）
- "然而""但是""却"的重复使用（检查段落间的逻辑连接词使用频率）
- "他看到了""他听到了""他感觉到了"等感官引导词的过度使用（通常可以直接写"看到了什么"）

## 写作建议

- 用动作、场景、对话表达情绪，不用情绪标签词
- 用具体数字和事实代替形容词堆砌
- 对话要有真实的停顿和跑题，不要功能性对话
- 句式长度保持多样性，长短句交错
