# 创作宪法

本文件是本小说的**最高创作原则**。当其他设定、brief 或 lorebook 与本文件冲突时，本文件优先。所有 Agent（leader、writer、director）在做出创作决策时必须以本文件为第一参考。

## 一、核心价值观

这部作品要传递什么理念？主角的旅程最终要证明什么？

- （填写核心价值 1，例如："弱者在压迫中觉醒并自我拯救"）
- （填写核心价值 2，例如："真正的力量来自理解而非征服"）
- （填写核心价值 3）

每一条核心价值观应该在剧情中以不同方式反复触碰、挑战和验证。不要在主题上"说教"——用角色的选择和后果来呈现。

## 二、不可妥协的质量标准

这些是底线。任何章节在以下标准不满足时不得视为完成：

- **角色能动性**：主角每章至少有一次主动选择（而非完全被动反应）。
- **章末钩子**：每章结尾必须留下继续阅读的理由（悬念/情绪悬念/信息悬念至少其一）。
- **展示 > 讲述**：关键情绪、关系变化和世界观信息优先通过场景展示，而非通过叙述总结。
- **信息边界**：任何角色不得知道他在当前时间点不可能知道的信息。
- （填写作品特定标准，例如："战斗场景必须≤2000字且节奏紧凑""伏笔必须在 20 章内至少推进一次"）

## 三、风格原则

- **叙事视角**：（第一人称 / 第三人称有限 / 第三人称全知 / 多视角）
- **语言风格**：（简洁冷峻 / 华丽细腻 / 口语化 / 文学性 / 网文节奏）
- **段落节奏**：（短段快节奏 / 自然段 / 长短交替）
- **对话占比**：（对话驱动 / 描写驱动 / 均衡）
- **内心独白**：（是否允许直接内心独白、占比限制）
- **幽默与严肃比例**：（纯正剧 / 轻松为主 / 悲喜交替）

详细文风规则见 `lorebook/instruction/writing-style/`，文风参考样本见 Writer profile 的 `writingReferencePreset`。本节的风格原则是**概要性约束**——当 writing-style 细节与本节的概要冲突时，本节优先。

## 五、读者契约

我们对读者做出以下承诺，必须兑现：

- **类型承诺**：（这部小说是什么类型，读者可以期待什么——例如"这是一部智斗为主的奇幻，不是升级爽文"）
- **节奏承诺**：（更新频率、章节长度、节奏倾向——例如"每章 2000-3000 字，每 3-5 章一个小高潮"）
- **情感承诺**：（读者可以期待什么样的情感体验——例如"不会虐主、不会无意义发刀、结尾是 HE"）
- **完结承诺**：（预计篇幅、是否保证完本——例如"预计 200 章完本，绝不太监"）
- **禁止内容声明**：（提前告知读者不会写的内容，避免期待偏差——例如"本书不写后宫、不写系统流、不写无脑打脸"）

## 六、使用说明

### 对 Agent 的约束

1. **写作前必读**：writer 在每次写作前应确认本文件的要求（由 inject.always 自动注入）。
2. **冲突裁决**：当 brief、lorebook 或 World Engine 数据与本文件冲突时，**宪法优先**。如无法调和，在 `report_result` 中标注冲突并要求 leader 解决。
3. **红线零容忍**：内容红线没有任何例外。即使 brief 要求或剧情似乎"需要"，也不得违反。

### 对用户的说明

- 本文件应在项目初始化阶段（`novel-workflow-02-project-bootstrap`）与 Agent 共同确定。
- 创作过程中可以修改本文件，但修改应谨慎——它影响所有已写和待写的章节。
- 如果发现某条宪法规则在实践中不可行，应主动修改宪法而非默默违反。
- 修改历史可在 `PROJECT-STATUS.md` 或 git log 中追踪。
